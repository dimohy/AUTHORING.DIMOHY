# AUTHORING.DIMOHY 히스토리

## r29 — 2026-04-28

### 주요 기능

- Issue-only 업스트림 개선 흐름 — 외부 사용자가 재사용 가능한 AUTHORING 개선을 Issue 생성 또는 Issue 초안으로 제안 가능.
- Maintainer Issue 검토 워크플로우 — 등록된 Issue를 분류하고 범용성을 평가한 뒤 승인된 변경을 일관되게 반영 가능.
- 리비전 히스토리 문서 — 리비전 상승 때마다 사용자에게 보이는 변경을 영어·한국어로 기록.

### 주요 개선

- 리비전 참조 최소화 — 사용자-facing 안내에서 언어 디렉터리와 일반 리비전 셀렉터를 우선 사용해 릴리스 변경 부담 축소.
- 영어/한국어 가이드 동기화 — 양언어 가이드와 진입 문서가 동일한 업스트림 개선 선택지와 maintainer 루프 설명 유지.
- 영어권 루트 안내 정리 — 루트 진입 문서에서 비영어 프롬프트 예시 제거, 지역화 예시는 한국어 안내에 유지.

### 주요 버그 수정

- TaskSync 세션 안정성 — 세션 재사용, `auto` 처리, 번호 선택지 폴백 규칙을 명확히 해 세션 증가와 선택지 미표시 방지.
- 오래된 업스트림 제출 문구 제거 — 재사용 가능한 개선이 일관되게 Issue로 전달되도록 오래된 대체 제출 표현 제거.
